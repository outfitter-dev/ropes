# Ropes core

`@ropes/core` exposes the Ropes quality engine and its versioned result parsers. The public API includes `explain`, `check`, and `fix`. Use Bun 1.4.4 or newer.

Install the exact canary version.

```sh
bun add --exact @ropes/core@0.1.0-canary.4
```
